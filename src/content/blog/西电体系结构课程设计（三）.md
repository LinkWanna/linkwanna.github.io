## 指令集设计

下面是我所设计的指令集，在不大规模修改硬件的前提下最多只能设计 8 条指令，主要展示了**过程调用**的能力，即函数调用（call）和返回（ret）。

| 指令 | 功能 |
| ---- | ---- |
| IN | 从按键中获取数据并存入 R0 |
| ADD | 寄存器加法，计算 RD = RD + RS |
| CALL | 调用子程序，具体参考下方 ABI |
| RET | 返回子程序，具体参考下方 ABI |
| ADDI | 立即数加法，计算 RD = RD + IMM |
| STA | 存储寄存器内容到内存 |
| LOAD | 从内存加载数据到寄存器 |
| JMP | 无条件跳转到指定地址 |

大部分同学应该实现的是**栈**的功能，相比于**栈**来说，过程调用的实现要更有难度也更有趣一些。当然，也不是说我们这里没有栈，栈可是过程调用的基础，否则没有办法保存状态，只是我们没有 `POP` 和 `PUSH` 指令而已。但实际上也可以这样进行实现的：

```asm
# 入栈
STA  R1, R2   		# Mem[SP] = R1
ADDI R2, R2, 0xFF  	# SP--

# 出栈
ADDI R2, R2, 0x01  	# SP++
LOAD R1, R2   		# R1 = Mem[SP]
```


### ABI Specification

ABI (Application Binary Interface) 规范，也就是用于定义架构和程序之间的接口规范。在这里主要定义了函数调用时寄存器和栈的使用规则：

1. 函数参数通过 R0 和 R1 传递
2. 函数返回值通过 R0 传递
3. SP (Stack Pointer) 指定为 R2
4. R0、R1 用于传递参数和返回值
5. RA 存储在栈上第一个地址处

有了这个 ABI 规范，我们才能够拥有一个完整的编程模型，才能好好地去写汇编代码（汇编器在附录中提供）。

### 微指令设计

每一条指令所需要的微指令是不一样的，通过 `engine.py` 提供的微指令解析的支持，可以很轻松地把每一条指令所需要语义转换成它的 16 进制形式，然后直接格式化输出到终端上即可。这就是计组课设的核心工作，如果用手写，那真的是工程量巨大的，但是如果是使用代码生成，那就变得非常简单了。基本上，只要写完了一个指令所对应的微指令，接下来就能使用这个模块，快速完成二进制形式的转变。

        self.S = S
        self.M = M
        self.Cn = Cn
        self.WE = WE
        self.A9_8 = A9_8
        self.A = A
        self.B = B
        self.C = C
        self.uA = uA

    def from_binary(value: str, pos=0):
        S = value[0:4]
        M = value[4:5]
        Cn = value[5:6]
        WE = value[6:7]
        A9_8 = value[7:9]
        A = value[9:12]
        B = value[12:15]
        C = value[15:18]
        uA = value[18:24]

        return Inst(S, M, Cn, WE, A9_8, A, B, C, uA, pos)

    def from_hex(value: str, pos=0):
        binary_value = bin(int(value, 16))[2:].zfill(24)
        return Inst.from_binary(str(binary_value), pos)

    def to_binary(self):
        return f"{self.S}{self.M}{self.Cn}{self.WE}{self.A9_8}{self.A}{self.B}{self.C}{self.uA}"

    def to_hex(self):
        return hex(int(self.to_binary(), 2))

def STA() -> List[Inst]:

def JMP() -> List[Inst]:
    """JMP: PC = RAM[IMM]
    1. AR = PC, PC += 1
    2. PC = RAM[AR]
    """
    I1 = Inst(S="0000", M="0", Cn="0", WE="0", A9_8="11", A="110", B="110", C="110", uA="000000")
    I2 = Inst(S="0000", M="0", Cn="0", WE="0", A9_8="01", A="101", B="000", C="110", uA="000000")

offset = 0
micro_start = 0x20
run_start = 0x01


def assign(list: List[Inst], head: int):
    global offset
    length = len(list)

    if list is None:
        return

    for i, inst in enumerate(list):
        # 第一条微指令的位置是 head
        if i == 0:
            inst.pos = head
        else:
            inst.pos = micro_start + offset

        # 第一个指令不需要增加偏移
        if i != 0:
            offset += 1

        # 最后一个微指令跳转到运行起始地址
        if i == length - 1:
            inst.uA = f"{(run_start):06b}"
        else:
            inst.uA = f"{(micro_start + offset):06b}"

        # print(f"{inst}")


def beautify(insts: List[List[Inst]]) -> str:
    # 用 "000000" 填充 64 条微指令
    table = []
    for _ in range(64):
        table.append("000000")

    for inst in insts:
        for i in inst:
            table[i.pos] = i.to_hex()[2:].zfill(6).upper()

    # 格式化输出：每行 8 条微指令
    result = ""
    for i in range(8):
        line = f"0x{i * 8:02X} "
        line += " ".join(table[i * 8 : (i + 1) * 8])
        result += line + "\n"
    return result

from typing import Tuple, List

opcode_map = {
    "IN": 0x00,
    "ADD": 0x10,
    "CALL": 0x20,
    "RET": 0x30,
    "ADDI": 0x40,
    "STA": 0x50,
    "LOAD": 0x60,
    "JMP": 0x70,
    "NOP": 0x00,  # 占位符，实际上不存在
}

type_map = {
    "IN": "R",
    "ADD": "R",
    "CALL": "I",
    "RET": "R",
    "ADDI": "I",
    "STA": "R",
    "LOAD": "R",
    "JMP": "I",
}

rd_map = {
    "R0": 0b00,
    "R1": 0b01,
    "R2": 0b10,
    "": 0b11,
}

rs_map = {
    "R0": 0b0000,
    "R1": 0b0100,
    "R2": 0b1000,
    "": 0b1100,
}


def parse(line: str) -> Tuple[int, int]:
    """opcode,rd,rs,imm"""
    slice = line.strip().split(",")
    opcode = slice[0].strip().upper()
    rd = slice[1].strip().upper()
    rs = slice[2].strip().upper()
    imm = slice[3].strip().upper()
    if imm == "":
        imm = "-1"

    if opcode == "NOP":
        return (0x00, -1)

    return (opcode_map[opcode] | rd_map[rd] | rs_map[rs], int(imm, 16))


def beautify(insts: List[int]) -> str:
    # 用 "00" 填充 64 条指令
    table = []
    index = 0

    for _ in range(64):
        table.append("00")

    # 填充指令
    for inst in insts:
        table[index] = hex(inst & 0xFF)[2:].zfill(2).upper()
        index += 1

    # 格式化输出：每行 8 条指令
    result = ""
    for i in range(8):
        line = f"0x{i * 8:02X} "
        line += " ".join(table[i * 8 : (i + 1) * 8])
        result += line + "\n"

    return result


def assemble(lines: str) -> str:
    ram = []
    for line in lines.splitlines():
        # 跳过空行和注释行
        if line.strip() == "" or line.strip().startswith("#"):
            continue
        inst, imm = parse(line)
        ram.append(inst)
        if imm != -1:
            ram.append(imm)

    return beautify(ram)
