## 前言

本文是西电计科专业微机原理随课实验的第一篇文章，主要介绍实验环境的搭建过程。
说起来微机原理的实验室里有一个专门的实验平台，叫做“星研集成环境软件”，但是这个软件实在是太过于陈旧了，而且有不少难以名状的问题（比如路径上的文件名不能太长，不然就会导致编译器找不到你的汇编代码）。出于这个原因，第一步我们当然是要搭建一个现代化的实验环境，用来写汇编代码和模拟运行。

## 实验环境搭建

我选择的方案是使用 `Vscode` 作为 IDE，搭配 `MASM/TASM` 插件内置的 `masm` 汇编器编译汇编代码为 `.exe`，最后将生成的可执行文件加载到 `DOSBox-X` 中运行。

### 下载与安装步骤

1. 首先，前往 [Vscode 官网](https://code.visualstudio.com/) 下载并安装最新版本的 Vscode。

![](/assets/images/blog/microcomputer-1/vscode.png)

2. 打开 Vscode，前往扩展商店，搜索并安装 `MASM/TASM` 插件。

![](/assets/images/blog/microcomputer-1/ext.png)

3. 下载并安装 [DOSBox-X](https://dosbox-x.com/)，这是一个功能强大的 DOS 模拟器，可以运行各种 DOS 程序。

![](/assets/images/blog/microcomputer-1/DOSBOX.png)

### 汇编的 Hello World！

新的语言和新的环境总是需要一个 Hello World！来热热身的，不过在此之前，需要先检查一下 `MASM/TASM` 插件的配置。

![](/assets/images/blog/microcomputer-1/check.png)

然后就可以新建一个汇编文件 `hello.asm`，输入以下代码：
```asm
.model small
.stack 100h

.data
msg     db      'Hello World!' ,'$'

.code
start:
    mov     ax, @data
    mov     ds, ax          ; 初始化数据段

    mov     dx, offset msg  ; DS:DX -> "$" 结尾字串
    mov     ah, 09h         ; DOS 功能：显示字串
    int     21h

    mov     ah, 4Ch         ; 带返回码 0 结束
    xor     al, al
    int     21h
end start
```

右键点击编辑器中的代码区域，选择 `运行当前程序`，插件就会自动调用 `masm` 汇编器将代码编译为可执行文件 `hello.exe`，并直接在 `DOSBox-X` 中运行。会弹出一个窗口，显示 `DOSBox-X` 的界面，里面就会打印出 `Hello World!`。

![](/assets/images/blog/microcomputer-1/run.png)

恭喜你！你已经成功搭建了微机原理的实验环境，并运行了第一个汇编程序！现在来解释一下上面的代码做了什么：

1. `.model small`：定义内存模型为小型模型，代码段和数据段各占一个段。
2. `.stack 100h`：定义堆栈段的大小为 256 字节（100h）。
3. `.data`：数据段开始，定义了一个以 `$` 结尾的字符串 `msg`。
4. `.code`：代码段开始，程序的入口点是 `start` 标签。
5. 初始化数据段寄存器 `DS`，将数据段地址加载到 `AX` 寄存器，然后再将 `AX` 的值移动到 `DS`。
6. 使用 DOS 中断 `21h` 的功能 `09h` 来显示字符串。
7. 使用 DOS 中断 `21h` 的功能 `4Ch` 来结束程序，并返回退出码 `0`。

#### Q&A
Q: `.model` 是什么意思？除了 `small` 之外还有其他的模型吗？

A: `.model` 定义了内存模型,用来确定代码和数据指针的大小，[官方文档](https://learn.microsoft.com/zh-cn/cpp/assembler/masm/dot-model?view=msvc-170)中还提到了其他的内存模型，比如 `tiny`、`medium`、`large` 等等，不同的模型适用于不同规模的程序。不过现代的 64 位的程序已经不需要声明了，因为它们默认使用 `flat` 内存模型。

Q: 我不声明 `.stack` 会怎么样？

A: 如果不声明 `.stack`，汇编器会使用默认的堆栈大小，通常是 1KB。但是对于一些需要大量堆栈空间的程序，建议显式声明堆栈大小以避免堆栈溢出。

Q: `.stack`，`.data`，`.code` 这些以点开头的指令是什么意思？

A: 这些是 `MASM` 中用于告诉汇编器如何组织代码和数据段。它们不是实际的机器指令，而是用于指导汇编器生成正确的机器代码。比如，`.data` 告诉汇编器接下来的内容是数据段，`.code` 告诉汇编器接下来的内容是代码段。具体这些**段**在二进制中是如何组织的，可以参考[程序员的自我修养](https://jp311.github.io/a-programmer-s-work/cover.html)。

Q: `int 21h` 是什么意思？

A: 分成两个部分来看，`int` 是中断指令，用来触发一个软件中断，`21h` 是中断号，表示调用 DOS 的功能。通过设置 `AH` 寄存器的值，可以指定不同的 DOS 功能，比如 `09h` 用于显示字符串，`4Ch` 用于结束程序。可以参考[这里](https://www.ctyme.com/intr/int-21.htm)了解更多关于 DOS 中断的信息（没错，网页很古老，但是有用）。
